# Focus Trail Reel design
1080 × 1920, 30 fps, 20 seconds. Real product footage, four scenes.
Cobalt #4b43d6 background, white headlines, navy #202342 text on cream cards.
Mint #c5eadb marks correct focus; peach #ffbba6 marks the controlled failure.
Local Manrope variable font: 800 headlines, 600 labels, 500 body.
Safe content: x72–972, y160–1550. Bottom 370px clear for Instagram controls.
Motion: explicit line slides using the installed line-by-line-slide recipe, 0.34s power3.out; one card settle per scene. No ambient loops.
Actual captured UI and report only. Key labels are editorial annotations synced to real events.
